# Emmanuel Otoo - Portfolio

A modern, fast, and accessible portfolio website built with Next.js 15, React 19, and TypeScript.

## 🌐 Live Site
**[emmanuelotoo.dev](https://emmanuelotoo.dev)**

## 🚀 Features
- ⚡ **Lightning Fast** - Optimized for performance with 95+ PageSpeed score
- 🎨 **Modern Design** - Clean, minimalist dark theme
- 📱 **Fully Responsive** - Optimized for all devices
- ♿ **Accessible** - WCAG compliant with proper ARIA labels
- 🔍 **SEO Optimized** - Complete meta tags, structured data, and sitemap
- 🎯 **Type Safe** - Built with TypeScript for reliability

## 🛠 Tech Stack
- **Framework**: Next.js 15 with Turbopack
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React, React Icons
- **Fonts**: ABCDiatype, PPMondwest
- **Analytics**: Vercel Analytics
- **Deployment**: Vercel
